Dicas rápidas

  • Clique neste ícone para acessar o menu Global, onde você pode:
    • Pesquisar usando SpeedSearch
    • Usar Ações rápidas para adicionar rapidamente uma Conta/Contato.
    • Usar Ir para para acessar todos os tipos de registro no cliente móvel.
    • Expanda Outros para acessar os recursos a seguir:
      • Usar Configurar menu para alterar os itens no menu Ir para e especificar a ordem em que eles serão exibidos. O primeiro item na lista na tela Configurar menu se tornará a sua exibição padrão e será carregado primeiro após você se conectar.
      • Usar Definições para limpar as credenciais salvas, limpar o armazenamento, acessar os logs de erro, esvaziar Minha maleta por meio da limpeza das Opções off-line, definir o cliente móvel para usar o relógio de 12 horas em vez do relógio de 24 horas e definir um novo idioma para o Mobile Client.
      • Localizar a Ajuda.
      • Encerrar sessão.
      • Conexão mostra se o seu Cliente móvel está Online (a barra de cabeçalho nos registros será exibida em azul) ou Offline (a barra de cabeçalho será exibida em cinza).
  • Clique neste ícone para acessar o menu Contextual (à direita) e as Definições de exibição. As opções disponíveis variam de acordo com o tipo de registro.
    • Consulte as hashtags disponíveis
    • Exibir KPIs (Indicadores-chave de desempenho)
    • Expanda Grupos, Configurar para selecionar os grupos a serem exibidos nas visualizações em lista. Isso está disponível nas exibições em lista de contas, contatos, leads, oportunidades e tíquetes.
    • Faça uma seleção em Layouts, disponível nas exibições em lista de contas, contatos, leads, oportunidades e tíquetes. O layout selecionado se tornará o padrão para quando você retornar a esse tipo de registro posteriormente.
      • O layout de resumo é exibido como 4 campos em 1 coluna. Esse é o padrão.
      • O layout de detalhes mostra como 9 campos em 1 coluna.
        Nota: se você tiver acesso ao Cliente Infor CRM SLX Web ou Windows, você poderá modificar a exibição de alguns campos nesses layouts Resumidos e Detalhados para dispositivos móveis.
        • Na exibição em lista de conta de clientes web, contatos, leads, oportunidades ou tíquetes, clique com o botão direito do mouse em uma guia de grupo, clique em Editar e, depois, clique na guia Layout:
        • Arraste e solte as colunas para alterar sua ordem.
        • Exibir campos de moeda em texto verde: selecione a coluna Potencial, clique em Editar, expanda o menu suspenso do campo Tipo de formato e selecione Moeda, clique em OK.
        • Exibir números de telefone como um link clicável: selecione Número do telefone, clique em Editar, expanda o menu suspenso Tipo de formato e selecione Número de telefone, clique em OK.
        Consulte a ajuda do cliente Web ou Windows para obter mais informações sobre a edição de grupos.
  • Este ícone indica que você pode expandir e recolher painéis para exibir/ocultar detalhes adicionais.
  • Novo: este ícone indica que você pode adicionar um novo registro ao Infor CRM SLX. Ele está disponível em todas as exibições em lista.
  • Quando o botão Atualizar estiver disponível, clique nele para atualizar imediatamente as informações. Selecione um registro para limitar a atualização para esse registro. Quando nenhum registro for selecionado, os dados de todo o grupo serão atualizados.
  • O texto azul em visualizações detalhadas significa uma ação de link (como navegar para uma URL ou ir para uma conta).
  • Nota: se você estiver usando um iPhone ou iPad e acessar o Infor CRM SLX Mobile a partir de um atalho na tela de início, o link do mapa será aberto em uma nova exibição e o link da Web estará desabilitado.

Ações rápidas

  • Nas exibições em lista, clique no ícone de reticências para ver e acessar atalhos aos recursos usados com frequência. As opções disponíveis variam dependendo do tipo de registro. (Alguns ícones de ação rápida podem não estar disponíveis. Por exemplo, em Minha programação, a ação Recusar estará indisponível se você já tiver aceitado a reunião).
  • Use Outros >Configurar menu para alterar a visibilidade e a ordem dos itens no painel Ação rápida.

Trabalhando offline

    Os recursos permitem o acesso somente leitura para selecionar registros e entidades quando o seu Cliente Móvel está desconectado ou perde a conectividade.
  • Recentemente visualizado mostra as visualizações detalhadas visitadas e disponíveis em caso de perda de conectividade. Recentemente visualizado está disponível no Menu global.
  • Minha Maleta permite que você selecione registros para ficarem disponível quando estiver offline. Para adicionar itens a Minha maleta, na exibição detalhada, abra um registro e, depois, clique no ícone da Maleta localizado na barra do cabeçalho. Todos os dados relacionados com esse registro também serão movidos para a Maleta. Quando você abrir um registro na exibição Minha maleta, a barra do cabeçalho estará sempre cinza porque Minha maleta está sempre no modo off-line.
  • Minha Programação mostra as atividades do dia. Minha programação está disponível no Menu global. Você pode mover todas as atividades na exibição de lista Minha programação para Minha maleta. Para fazer isso, abra a exibição em lista Minha programação e clique no ícone da maleta localizado na barra do cabeçalho.
  • Notas criadas durante a sincronização offline na próxima vez que você se conectar ao Infor CRM SLX.

Pesquisa

  • Existem várias maneiras de pesquisar:

    • No menu global, localize todas as contas, contatos, leads, oportunidades, atividades, notas/histórico e tíquetes relacionados. Insira mais texto para melhorar a precisão da sua pesquisa.
    • No menu contextual, filtre os resultados da exibição em lista usando palavras-chave com hashtag pré-definidas.
    • Para cada entidade, filtre os resultados da exibição em lista a partir da barra de pesquisa usando os campos especificados abaixo.

      Nota: clique no botão de alternância Contém para mudar o operador de “Inicia com” para “Contém” nas exibições de lista de Contas, Contatos, Leads, Oportunidades e Tíquetes.

Digitalizar cartão de visita

Disponível apenas para o Infor CRM SLX versão 10.1 e posteriores

  • Na exibição detalhada de um lead, clique em Digitalizar cartão. Siga as instruções para adicionar uma imagem ou tirar uma foto. Clique em Processar para editar e mapear o texto do cartão de visita aos campos de lead do Infor CRM SLX. Para mapear, clique no texto e, em seguida, clique em Atribuir ao lado do campo. Para dividir uma linha em campos separados, posicione o cursor no local onde deseja dividir e clique em Dividir. Quando terminar, clique em Confirmar.

    Nota: os formatos compatíveis são PNG, JPEG, TIFF e BMP
